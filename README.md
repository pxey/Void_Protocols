# VOID

## Useful help should not be limited by money.

VOID is an open idea and social protocol for making useful services accessible to everyone. It can live in any network, community, tool, or place where people help one another.

- **Give** something useful you can provide.
- **Ask** for help you need.
- **Help** by responding or connecting people.
- **Start** an independent VOID space wherever people already gather.

No permission, membership, mandatory account, payment, reputation, or central platform is required.

## What VOID is

VOID is a portable, open foundation for voluntary cooperation. Anyone may use, adapt, translate, build on, or fork the idea. Communities remain independent and may create their own rules, tools, and safety practices.

## What VOID is not

VOID is not a company, marketplace, membership system, accreditation authority, referral scheme, reputation gate, mandatory identity system, or single official community. This repository is one public reference space, not an owner or central authority.

## Start

Choose one useful action: give, ask, help, or start. Use the [Launch Kit](launch/LAUNCH_KIT.md) to create an independent space, and adapt it to your context.
