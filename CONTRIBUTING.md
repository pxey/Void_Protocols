# Contributing to VOID

Contributing to this repository does not require joining an organization. VOID is an open idea, and this repository is one reference documentation space rather than an owner of the idea.

You can contribute by:

- improving documentation;
- translating existing documents;
- proposing clearer principles;
- improving the protocol;
- building software or tools;
- creating independent communities;
- documenting real experiences;
- creating independent implementations;
- identifying contradictions;
- proposing better approaches; or
- forking the repository.

Please keep contributions clear, useful, respectful, and consistent with the open and decentralized character of VOID. Do not present this repository as the official owner, platform, or authority for every VOID community.

A contribution may be accepted, rejected, or modified in this repository. A different community may use it unchanged, adapt it, or develop an independent fork. No single repository can control the idea or its implementations.

When documenting an interaction, use real experiences only. Do not fabricate users, testimonials, statistics, or outcomes. Protect personal information and obtain consent before publishing identifying details.

For changes to this repository, open an issue or pull request with a concise explanation of the proposed change. Discussion is welcome, including disagreement and alternative approaches.
